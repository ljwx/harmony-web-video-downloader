# 验证范围

此文档说明已取得的证据与尚未验证的范围，不构成所有站点、系统或设备的兼容性保证。

## 宿主逻辑回归

命令：`node scripts/verify.cjs`，需要可用的 DevEco TypeScript 环境。

2026-11-05：16 项检查通过；2026-11-09 开源发布准备时重新执行，16 项全部通过。检查通过模拟 Harmony 服务执行实际核心源码，覆盖：

- 从分享文案提取链接、保留签名查询参数、拒绝无效输入。
- 旧版抖音视频分享页规范化、域名边界及避免改写正常移动页面。
- 页面提取脚本语法、媒体类型分类、页面切换后的异步结果隔离。
- 目标域 Cookie 和跨域 Referer 策略。
- HLS 清晰度、独立音轨、分片、初始化段及 AES key 的本地引用完整性。
- 直播、字节范围、DRM 拒绝；分片失败时不发布完成播放列表。
- 非视频响应校验、暂停前不发请求、异步创建期间取消。
- 任务去重、完成记录恢复、文件删除。

## 编译

HarmonyOS 6.0 SDK / API 20，compatible API 12。执行 `./scripts/build.sh`，已通过 ArkTS 编译和 HAP 打包。未配置签名；仍存在 SDK 异常处理提示。

## 模拟器验证

2026-11-05，针对单个公开抖音视频：

1. 从短链接进入时，将旧分享落地页转换为同一视频的普通网页地址。
2. 识别两条直链，选择其中一条创建下载。
3. 保持任务列表打开，完成状态及播放按钮自动更新。
4. 文件以 MP4 保存；系统播放器显示总时长 01:04，进度推进到 00:23。
5. 覆盖安装后，原有完成记录仍可读取。

该结果仅覆盖一个视频在当时模拟器环境下的直链流程。没有在仓库中包含视频文件、会话 Cookie、签名材料或原始设备日志。

## 未验证

- 真机、最低兼容系统版本与其他站点 / 视频。
- 本地 HLS、fMP4、独立音轨和 AES-128 的真实系统播放器兼容性。
- 计费网络、漫游、网络切换及进程后台行为。
- 系统真实续传、损坏视频、重定向头部转发。
- 所有暂停 / 恢复 / 失败 UI 分支的设备场景。

DASH、转 MP4、DRM、跨进程断点恢复未实现，不能据宿主检查或编译结果认定支持。
